# Agentic Nexus Ω — owner-local learning and model council

This extension adds five bounded, executable components. NEURAL NEXUS inventories checksum-verified native safetensors bundles in the owner-local acquisition directory, alongside the allowlisted installed Ollama inventory. Native CPU inference implements BERT attention, residuals, layer normalization, GELU, pooling and unit-normalized embeddings for only two explicitly supported repositories (all-MiniLM-L6-v2 and bge-small-en-v1.5). NumPy and tokenizers are required in the reviewed owner-local virtual environment. Other acquired families remain catalog-only. Native precision is verified by tensor layout and permitted floating-point dtypes, without pickle, remote code or arbitrary model imports. An inventory receipt is not proof of model training or scientific quality. Native inference has passed synthetic fixture tests; actual downloaded pretrained weights are not yet available or qualified. The BERT path must be compared to reference embeddings on real weights before relying on semantic quality.

SOVEREIGN SWARM generates five candidate synthetic policies, evaluates four shared training seeds, and exposes only training evidence and prior structured ballots to each local model in sequence. Constrained JSON-schema ballots cannot execute commands. RAM and Ollama availability are checked before each model dispatch, which uses an allowlisted model and a fixed local endpoint. No forced unload or swap override. Each ballot is evaluated against eight independent held-out seeds for all five candidates, with regret relative to the best observed candidate. The majority vote (ties broken by training score) is not automatically applied to any real system. A single successful ballot is allowed but is not evidence of multi-model consensus. Manifest identities are not proof of distinct underlying architectures. The chosen synthetic objective is arbitrary, not a scientific welfare function. Comparing five fixed policies is not evidence of broad agentic reasoning; a simple training-score baseline may outperform the models.

MNEMOSYNE stores an owner-local hash-chained, size-limited experiment bank using atomic replacement and a single-writer lock. Repeated seeds cannot enter adaptive memory; replay recomputes the complete synthetic evaluation, not model text. Hashes detect corruption, not malicious authorship. Retrieval by model/candidate is implemented, with optional cosine-similarity recall over native embeddings of synthetic missions. PROMETHEUS trains an actual small neural network on outcomes from at least four distinct historical missions, holds out complete missions rather than individual rows and compares MSE with the current mission's training-evidence predictor. METAMIND ranks candidate models by prior replay-verified regret, exploration and physical-memory admission. The numerical predictor and routing adapt; pretrained LLM weights are not modified.

## Operator usage
- `node scripts/agentic_council.mjs run PRIVATE_MEMORY_PATH 49022 8 2`
- `node scripts/agentic_council.mjs replay PRIVATE_MEMORY_PATH`
- `node scripts/agentic_council.mjs learn PRIVATE_MEMORY_PATH NEW_SEED STEPS`
- `node scripts/agentic_council.mjs recall PRIVATE_MEMORY_PATH NEW_SEED STEPS`
- Owner stdin operations: agentic_plan (seed,steps), agentic_council (seed,steps), agentic_native_catalog (no arguments), agentic_native_embed (model,seed,steps). Owner interface is stateless; persistent file operations are explicit CLI actions, not model-selected paths.
- Configure UMBRA_AGENTIC_NATIVE_PYTHON and UMBRA_AGENTIC_NATIVE_ROOT in the owner environment for native operations. No external network is used by native inference or simulation; Ollama calls are localhost-only. Use private paths outside Git.
- Tests: npm test; using the reviewed Python environment, python -m unittest discover -s tests -p test_agentic_native.py. No large model loading or dependency installation required for tests.
