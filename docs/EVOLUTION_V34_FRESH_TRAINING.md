# MYRIAD v3.4 ? independently initialized neural research bank
A new, separately labeled research cohort uses the historic 411,000-parameter
network geometry but starts from fresh deterministic seeds. It is not restoration
of the missing 8.22 GB historical bank or 640 MB ability bank.
Each cycle performs genuine CPU PyTorch AdamW gradient updates on generation-specific
synthetic mathematical targets, writes FP16 checkpoints and receipt chains, verifies
prior bytes before resuming, and compares fresh holdout, shifted data and an unseen
teacher function against the original and zero baselines. The unseen teacher is a
falsification control; no real-world or trading performance is claimed.
At most eight agents, 128 steps each, one CPU thread, 1 GiB private storage cap.
New candidate generations are immutable and stay quarantined; no automatic production
promotion. Stop on missing/corrupted checkpoint or exhausted quota, never delete
old weights. Windows execution requires the previously ACL-protected private directory.
Public CI uses disposable test weights, not any private archive.
