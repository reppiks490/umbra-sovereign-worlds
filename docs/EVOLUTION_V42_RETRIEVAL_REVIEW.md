# MYRIAD v4.2 ? retrieval-augmented source research
The MiniLM embedding model ranks actual allowlisted function excerpts for six
rotating engineering topics: leases, checkpoint integrity, scoring, resource
budgets, source citations and idempotent enrollment. The selected result is
re-read, its source bytes must match the retrieval digest, and its actual line
numbers are supplied to the pinned Qwen2.5-Coder 1.5B model. Generated findings,
experiments and risks remain private and inert. Citation structure is tested,
but a correct line number is not proof of a correct finding.
The retrieval window of the v4.1 serialized local controller runs this combined
workflow every two hours. The original worker and teacher schedules remain.
The review does not execute code, authorize merges or trade. Model registry
digests are observed locally and not independent publisher attestation.
