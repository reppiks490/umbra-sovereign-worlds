# MYRIAD v4.3-v4.4: authenticated recovery and paired qualification
Transient TimeoutError quarantine is recoverable only with a valid incomplete
receipt, matching occurrence seed, at most two lifetime failures, and repeating
identity. The original failed receipt, failure counter, and last successful HMAC
remain intact. The next occurrence is never earlier than the next hour after the
failed occurrence. The transactional recovery record does not claim a recovered
historical success. All other failure classes remain quarantined.
The weekly paired qualification uses the same four predeclared specialist cases
for each local model. Scores are independently replayed from raw structured
outputs, with an HMAC and task-set digest. The comparison is diagnostic only;
no automatic routing promotion is authorized by four cases.
The five-minute controller preserves teacher and retrieval windows and reserves
four daily worker windows for qualification. Existing local scripts remain
available. A failed model inference is not proof of competence and does not
count toward an accepted curriculum. Private model evidence stays local.
