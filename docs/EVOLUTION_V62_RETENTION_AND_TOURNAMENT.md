# MYRIAD v6.0?v6.2: distinct algorithms and task-conditioned retention
v6.0 adds 34 executable algorithms, bringing the identified inventory to 62 general methods plus 19 optimizers. Parameter recipes do not count. Randomized and direct reference tests are included.
v6.1 addresses the failed v5.8 conflicting-curriculum experiment (0/8 qualification) by freezing each original 1.5M-parameter model and learning a separately selected 21768-parameter residual adapter. Original task inference does not execute the adapter, hence exact retention on that route is architectural, not proof of generalized memory. New task evaluation compares source, zero and training-only linear baselines on fixed synthetic holdout and shifted distributions. Sixteen actual local adapters passed these gates, 4096 gradient steps and 696576 FP16 bytes. Original and failed v5.8 weights remain intact. No production authority.
v6.2 pairs identical seeded cases for all 16 research specialties, partitioned eight per inference request. It records decision/evidence scores separately, model identity, latency and failures; replay verifies HMACs and scores. Least-attempted pending model/partition selection avoids repeated failures monopolizing the schedule. Large models remain memory-gated. No automatic routing admission from small synthetic cohorts.
The existing v5.9 scheduler retains its windows, substitutes v6.1 for continued-training windows and v6.2 for benchmark windows. v4.7 numeric bank and v5.1 original bank are unchanged; residual adapter bytes are separate. Telemetry counts 62 general algorithm implementations, not all 81 identified methods. Full scale, sustained coverage, semantic ability certification and independent final generalization remain open.
