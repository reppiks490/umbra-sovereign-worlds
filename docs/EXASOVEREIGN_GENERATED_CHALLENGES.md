# EXASOVEREIGN authored challenge stream (v1)

This is an evaluation-only lane in the existing research portfolio, not a second training system. Seven domains: arithmetic (including the owner's original diagnostic expression), offline market accounting, UMBRA-like world state, event time, pseudocode tracing, statistics and resource planning. Each domain has four developmental tiers and up to one billion deterministic parameter addresses per tier. Address space is not a count of acquired questions, independent semantic skills, executed tests or training examples. Generated prompts and their exact arithmetic labels are never eligible for EXASOVEREIGN source-only weight training.

The local SQLite ledger reserves model/digest/domain/tier/ordinal before inference, rejects duplicate attempts, finalizes outcomes once, and regenerates question identities and scores from recorded responses. Interrupted reserved records are unknown, not completed. Choose the least-tested admitted language model and skill; advance a tier after eight consecutive correct developmental records at that tier. This is a narrow progression heuristic, not independent mastery. Failures expose a source lesson topic; selecting authenticated lessons and running targeted model-specific native adapters remain separate work. Never claim a matching Ollama model trained from another native checkpoint. Native/specialist evaluations, semantic diversity, authenticated data ingestion, independent holdouts, scalable ledger sharding, corrective training and retention are outstanding.

Run from the existing worktree with the native venv: scripts/generated_challenges.py --root <local-root> --count 2; audit with --audit. Existing model-compute lock, roster, RAM admission, disk reserve and 256 MiB ledger cap apply. No private receipts committed, no trade authority, no model promotion. Ordinary software tests are not model inference. Do not count generated challenge calls as authentic source benchmarks.
