# EXASOVEREIGN Ω — pre-December 18 campaign
Owner's planned 4 TB upgrade: December 18, 2026; not yet acquired or verified. Objective: deliver measurable capability before the storage expansion, not only architecture and downloads. Existing 28 GB neural cap supersedes the unfinished 40 GB proposal in this campaign; no extra Ollama downloads authorized in this allocation. The 15 GB resource queue is a cap, not a claim that 15 GB of sources are available or necessary.

## Acquisition architecture
Neural downloads first, then intelligence-resources.py uses the existing owner-local INFINITY scheduler. Separate 15 GB resource envelope: science 2, finance 2, reasoning 2, graphs 1, symbolic .5, algorithms .5, experience 1, simulation 1, causal .5, benchmarks 1, synthetic .5, cognition .5, reinforcement .5, semantic 1.5, evolution .5 (decimal GB). Retain 3 GB free floor, full 3 GB learning headroom, remaining 4.5 GB training bootstrap allowance. The queue accepts only license-screened pinned datasets with publisher SHA256 and safe relative data paths, and pinned PyPI compatible wheel artifacts with SHA256. No package installation or remote dataset scripts; downloaded content is untrusted. Candidate metadata rejection is fail-closed. Each file receipt is recorded only after download digest verification. Dataset train/evaluation tags are preliminary; semantic deduplication and independent split audit required before ingestion. No financial transaction authority.

## Campaign: deliverables and exit gates
- Nov 25–28: complete/resume neural transfers and native checkpoints; qualify source inventory and receipts; document actual available RAM, free disk and loaded-model concurrency. Independently benchmark each usable specialist on at least one domain-specific test. Reject invalid inputs and preserve baseline outputs.
- Nov 29–Dec 3: implement typed local adapters for available forecasting, chart extraction, speech, entity recognition, visual retrieval and verification. Route via a calibrated capability matrix. Compare 0.6B coordinator alone vs tool-equipped 0.6B vs 4B/8B and 27B where runnable; report accuracy, abstention, latency, peak memory, failure count. Never claim general superiority from specialist tasks.
- Dec 4–8: validate corpus licenses, schema and source identities; separate train/validation/retention/transfer; reject exact and near duplicate questions across splits. Run the existing Qwen/Granite replay and bounded LoRA optimizer when bootstrap is ready. Record actual gradient steps, loss, adapter digest, retention and transfer results; baseline stays active unless promotion gate passes.
- Dec 9–13: connect verified learning experiences to routing and quality-diversity trials. Build reproducible task tournaments, counterfactual/causal experiments and scientific numerical cross-checks. For market research use chronological splits, realistic fills/costs, no leakage, no live orders. Track independent evidence and false-confidence rate.
- Dec 14–17: regression, restart and resource-pressure trials; audit model registry, provenance, reproducible benchmarks, recovery behavior, rollback and local source inventory. Prepare migration manifest with checksums, current paths, storage budgets, required backups and staged copy/verification. Do not assume a new drive or move/delete existing files.
- Dec 18: owner-controlled storage migration only after verifying drive presence, format, capacity and transfer destination. Reallocate based on measured workloads and preserve the old drive until checksum and functionality checks pass.
