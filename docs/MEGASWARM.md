# MEGASWARM Ω — shared-weight specialist training (2026-11-24)

## Scope and operating facts
The owner requested thousands of Qwen3 0.6B and Granite4 350M agent instances, continuing training and reasoning improvement, cross-model and neural teachers, and downloads of missing training dependencies. The implemented population is 4,096 durable logical instances (2,048 per family), each with an identity, domain, strategy, attempts, wins and receipt-backed history. They share two existing Ollama weight sets; they are not 4,096 independent model copies or simultaneous processes. Eight generated-task domains are executable, representing 2,048 instances; remaining domains are registered but not runnable until adapters and verification exist. No arbitrary tool execution or real-world production authority.

The worker admits one model generation at a time, at most two students and one teacher per cycle. It checks current identity, idle Ollama and available physical memory, uses constrained JSON, independently grades generated tasks, and saves exact receipts. It rebuilds outcome state from those receipts and does not pretend a registered agent has executed. Teachers are independently admitted installed models, preferentially other families or larger models. Only independently correct answers enter lessons. Student prompts can include up to two prior verified examples with different teacher identity, seed and exact prompt; lesson receipt hashes remain attached to student outcomes. The first live teacher was Qwen3 1.7B: one correct arithmetic example. Four worker instances have executed four tasks, eight questions in total, five correct and one fully successful task. No causal teaching improvement established.

## Native adapter training path
scripts/native_lora_train.py implements bounded CPU LoRA training on verified native checkpoints and source-derived supervised examples. It checks all source hashes, loads local safetensors with trust_remote_code=False, freezes base parameters through PEFT, uses q_proj/v_proj rank 4, answer-only loss, gradient clipping and four optimizer steps per scheduled pilot. Existing accepted adapter (if any) is loaded only after checking its hashes; source weights never overwritten. Retention NLL must not increase by more than .02 and transfer NLL must improve by .01; accepted adapters written to new immutable directories, active pointer updated. This is a small pilot gate, not general capability proof. Actual optimizer execution and architecture compatibility remain unverified until runtime and sources finish. RAM admission: >=7.5 GB free Qwen, >=4.5 GB free Granite; current free RAM observed ~3.7 GB; no NVIDIA tooling verified. A full Q8 teacher requires much more available memory than this PC has under current gate. Learned adapters are private, not automatically used by Ollama or deployed to every agent; adapter inference/load and per-agent adapter assignment remain work.
