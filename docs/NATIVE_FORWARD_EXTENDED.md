# Extended native forward qualification

Adds explicit offline seq2seq (T5, LongT5, BART), BART classification, Whisper, Wav2Vec2 CTC and visual feature-extraction (ViT/DINOv2) routing. Chronos/T5 forecasting remains deliberately excluded from language generation. Synthetic bounded waveform, mel feature and pixel fixture inputs exercise model forward execution only; they are not ASR, image or reasoning competency tests, and do not represent model training. Preserves full-receipt checks, exact load checks, shared hardware locks, memory admission and no production authority.

Failing-first evidence: seven tests failed before implementation (three route assertion failures and four unsupported-architecture errors); all seven passed after implementation, including real offline tiny fixtures for T5, ViT, Whisper and Wav2Vec2. Combined native Python suite 269/269 passed, 21.291s. Initial full run deferred at 1711952 KiB free RAM; retry admitted at 3525236 KiB. Transformers emitted torch_dtype deprecation warnings. Catalog: 159 entries, 47 candidates (+12), 112 unsupported, no invalid metadata. Actual downloaded pretrained models have not been executed because the native bootstrap still owns its lock. Not deployed; requires independent CI and review before integration. TIMM, numerical forecasting, multimodal, detection/segmentation and other unsupported cases remain separate work.
