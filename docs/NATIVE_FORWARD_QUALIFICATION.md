Supported routes are allowlisted encoder, causal, classification and vision architectures. Local-only Transformers loading, no trust_remote_code, exact load information, finite nondegenerate output and SHA-256 receipt. Unlisted files, missing keys and unsupported architectures fail closed. No production, research competency or training authority.

Actual downloaded-model execution deferred while native bootstrap owns its lock. No new dependencies installed. CLI accepts explicit write-once output; do not launch multiple models in parallel on constrained machine. Existing service is unchanged; review before scheduling.
