# UMBRA compute MCP — local integration

This draft extends the combined core PR #25 without modifying production or MYRIAD training schedules. It imports the actual engine, civic layer, Court, independent replay helper and registered experiment CLI. No substitute simulation, network listener, deployment, arbitrary command tool, automatic training or self-promotion.

Start from a reviewed checkout of this branch with Node 22. In a compatible local MCP host configure a stdio server named umbra-compute, executable node, argument the absolute path to mcp/umbra_server.mjs. Five tools are exposed: simulate, paired experiment, independent replay, Reality Court, and one registered case. Registered cases span U0301–U5300, execute one per request with finite timeout, and verify the returned digest. Basic calls admit 1–120 turns and paired calls 2–8 trials. The process accepts a maximum of 64 validated calls per session. The JSON-RPC bridge supports the common lifecycle/tool subset; full protocol compliance has not been independently certified.

Optional MYRIAD checkpoint tool: a local operator can configure UMBRA_MYRIAD_PYTHON (absolute path to compatible Python executable with torch installed) and UMBRA_MYRIAD_BANK (absolute path to their existing v51 checkpoint root). Neither is a tool argument. The server exposes evaluation only when both are configured. Use the existing machine resource admission rules before launching. It reads one numeric agent directory, rejects linked paths and invalid receipts, verifies weights and independently replays scores. Optional 32 numerical features produce eight model outputs. These networks learn synthetic regression tasks, not general reasoning. No raw weights or private filesystem paths are returned. No training tool is exposed. Keep the bank immutable and locally access-controlled.

The copied original v51 source is blob 476429dac66f737552f7680d7261d36a77313c24 from MYRIAD research commit 4fa553d403884fbe05a9838dc297eb861ea6c83c. Protocol tests passed 3/3 in local Node 22. Checkpoint tests passed 3/3 on Python 3.13/PyTorch 2.10 CPU, including one genuinely trained isolated synthetic fixture, forward inference and tamper rejection. This is not an evaluation of the owner's existing weight bank. Actual engine CI is required. Run optional checkpoint tests with python -m unittest discover -s tests -p test_checkpoint_eval.py -v in an isolated test environment; the test generates a disposable fixture.

No hosted authenticated MCP endpoint is available in this session. A stdio process cannot be reached directly by the iPhone. Do not treat the plugin's private account release, a GitHub branch, or a normal website URL as a hosted MCP server. An approved remote transport with authentication and end-to-end tool discovery is a distinct remaining integration task.
